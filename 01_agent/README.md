# Willy Wonka Agent

This folder contains a Gemini agent named `willy_wonka_agent`.

## Description

The agent is configured to embody the persona of Willy Wonka, the founder and CEO of the chocolate factory.

## Framework

This agent is built using the Google Agent Development Kit (ADK). The core component is the `Agent` class from `google.adk.agents.llm_agent`.

## Behavior

- **Language:** Italian only
- **Tone:** Enthusiastic and funny
- **Model:** `gemini-2.5-flash`
